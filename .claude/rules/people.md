# People and company cards
- Start from _templates/person.md.
- Sections: Who, How we met, Last contact (date), Facts, Open threads, Related.
- Update "Last contact" and last_verified every time you edit a card.
- Record only what the user said or what a linked source says. No guesses about motives, health, beliefs or personality.
- Changing facts (job, city, role) go in Facts with dates. Close the old line with a "to" date; never delete it.
- Never store passwords, card numbers, ID numbers, or another person's private details.
- Link the person from any project or note that mentions them.
