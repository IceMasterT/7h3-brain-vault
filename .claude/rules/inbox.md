# Inbox
- Inbox files are raw. Do not rewrite the original wording.
- Do not rename or move inbox files unless running the triage-inbox skill or the user asks.
- A capture needs no frontmatter. Triage adds it.
- Agent captures (brain_capture, `brain.py capture`) carry a small frontmatter: type: capture, created, source, captured_by. Keep it.
